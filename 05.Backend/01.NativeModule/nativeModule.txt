File System Module 
---------------------
->The file system is a native module or library which holds function to manage and
access file on local storage of computer ie localhost or server storage 

->and in order to start using it we need to "import" the [node:fs] module in our index.js file 
or we can use the "require" syntax of the CJS ie commmon JavaScript pattern to runn bits of 
code that we need from the node:fs module

->import method is part of newly ESM ie EcmaScript6 Module and require is part of CJS
ie common js pattern

->File system module source code is at :
{https://github.com/nodejs/node/blob/v21.7.3/lib/fs.js}

->To use the promise-based API :
CJS:const fs = require('node:fs/promises');
ESM:import * as fs from 'node:fs/promises';

->To use the callback-based and synchronous API:
CJS:const fs=require("node:fs");
ESM:import * as fs from 'node:fs';
